# kubernetes

Tools for working with Kubernetes clusters and kubectl.

| Tool                  | Language | Description                                               |
| --------------------- | -------- | --------------------------------------------------------- |
| [decode-secret](decode-secret/) | Bash | Print the decoded values of a secret |
| [es-refresh](es-refresh/) | Bash | Force an External Secrets ExternalSecret or SecretStore to resync |
| [kswitch](kswitch/)   | Bash     | Switch kubectl context by name or with an arrow-key picker |
| [op-token](op-token/) | Bash     | Create the onepassword-token secret for the 1Password integration |
